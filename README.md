# 🏗️ Stack Tower Game

A lightweight, arcade-style tower building game built purely with web technologies. Drop moving blocks precisely on top of each other to stack the tallest tower possible. Miss the alignment, and your block gets chopped!

## 🚀 Live Demo

Play the game directly in your browser:  
👉 **[Play Stack Tower Game Live](https://alibabadevx.github.io/stack-tower-game/)**

---

## ✨ Features

* **Physics-Based Stacking:** Precision timing mechanics determine block alignment.
* **Dynamic Truncation:** Blocks automatically shrink when misaligned, increasing the difficulty.
* **Score Tracking:** Keeps real-time track of your current score and highest tower layer.
* **Pure Web Stack:** Zero dependencies, heavy frameworks, or external engines required.

---

## 🛠️ Built With

* **HTML5:** Structural layout and canvas rendering elements.
* **CSS3:** Responsive layout positioning and UI accents.
* **JavaScript (ES6):** Game loop logic, collision detection, and animation frame updates.

## 📦 How to Run Locally

You do not need to install any compilers or local servers to run this project.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AliBabaDevx/stack-tower-game
   ```

2. **Navigate into the directory:**
   ```bash
   cd stack-tower-game
   ```

3. **Open the game:**
   Double-click the `index.html` file to launch the game instantly in any modern web browser (Chrome, Edge, Firefox, Safari).

---

## 🎮 How to Play

1. A block will slide back and forth across the screen above the stack.
2. Tap the **Spacebar** (or click the screen) to drop the block.
3. Align it perfectly with the block below it.
4. Any overhang will be cut off, making your next platform smaller!
5. The game ends when a block completely misses the tower underneath.
